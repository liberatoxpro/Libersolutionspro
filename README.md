# LIBER DRONES PRO — Grupo Liberato

Projeto isolado na branch `liber-drones-pro` (a branch main permanece intacta).

Escopo: clientes e talhões, operações de pulverização e semeadura, cálculos de insumos e calibração, relatório PDF e clima. Misturas: apenas orientações gerais; sequência específica depende de rótulos/bulas e teste de compatibilidade. Não recomendar dose automaticamente.

## iOS
O GitHub Actions pode compilar um IPA não assinado com `xcodebuild` e `-allowProvisioningUpdates` quando o projeto iOS e o runner estiverem configurados. Para instalar com ESign é necessário um IPA corretamente empacotado e uma assinatura/provisionamento válidos. Não inclua certificados ou chaves no repositório.
