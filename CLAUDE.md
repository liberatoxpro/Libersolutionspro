# Instruções para o Claude

## Instagram (@liberdrones)

Para qualquer tarefa de Instagram com as skills do plugin `instagram-skills`
(`ig-caption-writer`, `ig-content-planner`, `ig-carousel-planner` etc.), use
`.claude/instagram/voice-profile.md` como perfil de voz e marca no lugar de
`references/voice-profile.md` do plugin. Escreva sempre em português do Brasil.
Quando o perfil for atualizado (ex.: `ig-humanizer --mode profile`), grave as
mudanças em `.claude/instagram/voice-profile.md`.
